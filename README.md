🧬 Protein Folder
Protein Folder es una aplicación web interactiva que permite explorar y visualizar el proceso de plegamiento de proteínas. Este proyecto es un fork del repositorio original de verinikita.

⚙️ Tecnologías utilizadas
Frontend: HTML5, CSS3, JavaScript

Backend: [Repo](https://github.com/ramaffei/API-ProteinFolder)
Hosting: VPS Propio

📁 Estructura del proyecto
/assets: Recursos como imágenes y otros archivos multimedia.

/css: Hojas de estilo para el diseño de la aplicación.

/js: Scripts de JavaScript que manejan la lógica y la interactividad.
